KyPanel runs shared and reseller hosting on AlmaLinux, Rocky Linux, CloudLinux and Ubuntu: accounts, email, DNS, databases, backups and Git deploys, with every account isolated. One price per server.

### Repositories

* [feedback](https://github.com/KyPanel/feedback): bug reports and feature requests
* [translations](https://github.com/KyPanel/translations): the panels in your language
* [docs](https://github.com/KyPanel/docs): the pages of docs.kypanel.com
* [cli](https://github.com/KyPanel/cli): `ky`, the command line
* [whmcs-module](https://github.com/KyPanel/whmcs-module): provisioning module for WHMCS
* [blesta-module](https://github.com/KyPanel/blesta-module): provisioning module for Blesta
* [fossbilling-module](https://github.com/KyPanel/fossbilling-module): server manager for FOSSBilling
* [paymenter-module](https://github.com/KyPanel/paymenter-module): server extension for Paymenter
* [clientexec-module](https://github.com/KyPanel/clientexec-module): server plugin for Clientexec
